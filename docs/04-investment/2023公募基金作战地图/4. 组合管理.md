# 组合管理
解决投后跟踪问题

** Outline **
管理流程
- 定目标
- 做配置
- 管收益
- 盯策略
- 诊持仓
- 做调研
- 读季报

## 1. 定目标
### 1.1 三大因素（不可能三角）
1. 预期收益率
2. 可投资期限
3. 风险承受能力
## 2. 做配置
### 2.1 根本原因
1. 可以有效的降低收益的波动性，拿得住，帮助投资者在中长期获取更好的收益
2. 资产配置的动态再平衡，可以解决投资择时的问题
3. 将钱分现在不同篮子里分散风险，避免出现较大的亏损
### 2.2 资产配置型基金产品方案
1. 固收+类基金
以风险较低的债券等固收类资产提供基础收益，在控制波动的前提下，配置其他类别资产提高组合收益的基金
2. 混合类基金
可以同时投资纯债、可转债、股票等多类基础金融资产。
3. 混合类FoF基金
相较于混合类基金直接投资基础金融资产，FoF则以债券基金、混合基金、股票基金等基金为主要投资对象。
相对于混合类基金，进一步做了分散
4. 投顾类产品
产品形态跟FoF比较类似，但是额外提供以客户需求为导向的顾问陪伴服务。结合投资者的偏好风险，投资目标进行投资。

## 3. 管收益
### 3.1 投资复盘时该看哪个收益率？
||时间加权收益率|资金加权收益率|
|---|---|---|
|衡量维度|衡量你买的组合好不好|在组合确定的情况，看你的买卖操作好不好|
|特点|与投资者的买入卖出行为无关，只衡量被投资产品的涨跌幅，及时追涨杀跌，也不会影响该收益率|与投资者的买入卖出行为相关，如果追涨杀跌，会拉低该收益率|
|什么时候用|看投资收益不达标，是不是买到的产品不好|看投资收益不达标，是不是自己的操作不好|
|怎么算|隔段时间收益率的几何加总|收益率/加权成本|
|延伸|一般公募基金收益率即该收益率|亦称资金占用收益率，也是自己的IRR|
### 3.2 如何正确评估投资效果
1. 衡量投资过程的收益率
    1.1 资金加权收益率
    由于投资过程中资金的转入、转出，不同资金投资占用时长也不同。该收益率考虑了投资过程中资金进出影响，也称资金占用收益率，内部收益率。
    1.2 时间加权收益率
    不考虑投资过程中的资金进出，只计算组合内基金自身整体的涨跌幅。反映的是所购买的产品组合涨跌幅，类似于基金的净值涨跌幅。
2. 衡量投资结果的收益率
    2.1 累计收益率
    用户投资某只基金以来，产生的所有受益于投入本金的比值。
    2.2 持有收益率
    用户持有收益与持有成本的比值，此种计算方法中，用户卖出后，持有收益同步减少，但是持有成本保持不变，不会出现收益率大幅上升的情况。
    2.3 持仓收益率
    用户持有收益与持有成本的比值。此种计算方法中，用户卖出后，持有收益与卖出前相等，但持有成本回同步减少，因此在盈利时卖出，可能会出现该收益率变得特别大的情况。
### 3.3 盯策略
1. 补仓加仓策略
各类定投方法：无脑定投、均线定投、按照市场估值定投等
测水温补仓法：持有收益率每下跌X%，买入一定份额
趋势反转补仓：投资标的在下跌过程中反弹X%后，买入一定份额
2. 减仓止盈策略
目标收益率止盈法：投资标的达到用户预期的收益率后止盈卖出
收益回撤止盈法：盈利收益率达到一定比例后，收益回撤X%后止盈卖出
指标分析止盈法：基于市场估值指标、技术指标等判断止盈卖出
### 3.4 单只基金跟踪的四大关注因素
1. 持有人结构：机构投资者，FOF基金对基金持有变动情况；基金公司、基金经理对基金持有变动情况。
2. 基金规模、持有人户数：基金规模与持有人户数是否快速大幅增加
3. 基金持仓变动：基金本身投资风格是否稳定，基金经理是否变更导致基金风格变更；持仓的最新动向、特点，有无大幅调仓等。
4. 质量稳定性：基金收益、风险、业绩稳定性等长期排名是否稳定，是否大幅下滑。
### 3.5 考虑替换基金的五大理由
1. 更换了不信任的投资经理
2. 基金经理投资风格经常漂移投资框架不稳定
3. 基金在同类中表现持续落后
4. 基金规模迅速膨胀，可能超出投资经理管理能力
5. 不看好基金重仓板块的未来表现
### 3.6 为什么要基于市场环境进行再平衡
再平衡是指当资产配置与投资目标出现偏离时，及时调整各类资产权重重新与初始目标相匹配的策略。
1. 再平衡可以控制风险：组合中哪一类资产因为上涨而导致占比过高，就定期调低该类资产的比例，相应调高其余资产的比例。这样可以兑换某类资产大幅上涨后的收益，避免后续该类资产大幅下跌产生的风险。
2. 再平衡还能实现逆向投：再平衡使投资者坚持调整期内表现更好的资产，并增持表现较差的资产。由于资产价值的“均值回归”特性，减低此前强势资产，增持弱势资产，真正实现了低买高卖，也就是逆向投资的精髓。
### 3.7 指标监测维度
1. 指标提醒：恐贪指数提醒、券商军工PH值、新能源TF值、股债性价比、指数估值
2. 基金收益提醒：最大回撤、持有收益率估算涨跌幅
3. 基金舆情提醒：持股、持债发生重大新闻，基金经理自购、减持、工作变动等新闻，分红、申赎状态改变、规模变化
4. 账户提醒：账户整体收益率变动
## 4. 诊持仓
### 4.1 为什么要做持仓诊断
1. 对投资者而言：整体收益需要对其目标，检视体验是否符合风偏，持仓基金需要优胜劣汰，资产配置需要均衡分散
2. 对财富机构（理财师）而言：帮助客户优化配置，增强客户粘性、建立信任，提高自身专业能力
### 4.2 如何进行投资复盘
目标偏离？浮亏是否可承受？浮亏原因分析是否有重仓某一板块？操作是否频繁是否追涨杀跌？根据市场环境，持仓的大类资产分布是否可优化？
### 4.3 组合持仓跟踪的五大风险源
1. 大类资产分布 2. 行业分散度 3. 风格分散度 4. 赛道分散度 5. 基金相关性
## 5. 做调研
### 5.1 产品设计
1. 产品类型
2. 投资范围：仓位范围，港股、期货？QDII额度
3. 开放形式
4. 费率要素
5. 渠道合作：重点代销机构、券商结算机构、ETF的重点做市商及政策、规模稳定性，个人机构客户结构
6. 绩效目标：收益目标
7. 回撤控制
8. 管理体系：产品什么部分管理、股债部分的决策和权限分配情况如何
9. 产品定位：团队管理产品的谱系、各产品之间的定位差别
### 5.2 投资团队
1. 团队背景
2. 稳定性
3. 决策机制
4. 资产配置

6. 选股思路
7. 选债思路
8. 挑战问题：规模容量、跳槽原因、踩雷个案、历史回撤等

6. 公司治理

## 7. 解套四步法
### 7.1 四步法
1. 归集账户：统一管理跟踪盈亏
2. 诊断问题：对齐目标、发现问题
3. 均衡调仓：均衡调整，汰弱留强
4. 赚钱补仓：捕捉机会，赚钱补仓
### 7.2 投资管理时的是个不要
1. 不要错误估计资金的可投资期限
2. 不要太过看重短期结果，忽略复利效应
3. 不要忽略购买力贬值风险，只重视资产波动性风险
4. 不要忽视投资中各种费用的影响
5. 不要只想获得收益不想付出任何代价
6. 不要以最佳表现衡量各类资产未来的回报率
7. 不要让情绪、信心、耐心剧烈波动
8. 不要忽视资产配置的不可能三角
9. 不要高估自己投资组合多元化的水平
10. 不要过高估计自己的风险及流动性承受能力
### 7.3 管组合时的四大误区
1. 频繁交易
交易成本是投资收益的隐形杀手，频繁交易基金的手续费成本，比大家想象中更高。
某只权益基金，按照3万元，一个月内买入卖出2次来计算。光申购赎回费要大约390元，相当于30杯奶茶。
2. 做甩手掌柜
长期投资不等于做甩手掌柜。需要定期监测账户的情况。
基于资本市场环境，自身投资需求、目标，组合产品发生的变化，及时进行再平衡等优化调整。
3. 过度关注组合短期表现
资本市场的短期波动都是很随机的，短期投资收益更多受到投资者情绪的影响，无法反应市场长期的真实价值。
要始终坚信短期业绩无法代表未来的走势。
4. 只关注单一资产或单一产品表现
投资组合就像一个团队，构建组合时看中的就是产品之间互补的特点，单只产品再优秀也有自己的短板、保持多元化，才能降低单一资产的风险。
### 7.4 导致亏损的五种投资行为偏差
1. 追涨杀跌 - 倒三角式加仓
2. 频繁交易 - 一有风吹草动就买卖
3. 处置效应 - 亏的不卖
4. 近因效应 - 情绪操作
5. 过度自信 - 买卖强化
